This is the part of the site where I write things down.

There's no comment section, no newsletter popup, no estimate of how many minutes
you'll spend reading. A post is a markdown file. When I'm done with one, it goes
in a folder, the site rebuilds, and it shows up here. That's the whole pipeline.

I wanted the writing to outlive whatever framework I happen to be using this year,
so the source of truth is plain text. Everything else — the styling, the build,
the server — is replaceable around it.
